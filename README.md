# 🎬 Movie Explorer

A modern and responsive movie discovery web application built with **React** and **Vite**. Movie Explorer allows users to browse, search, and explore movies through a clean and user-friendly interface.

## ✨ Features

* 🎥 Browse movies
* 🔍 Search for movies
* 📄 View movie information
* ⭐ Explore ratings and movie details
* 📱 Responsive design for desktop, tablet, and mobile
* ⚡ Fast development and optimized performance with Vite
* 🎨 Clean and modern user interface
* 🔄 Dynamic movie data

## 🛠️ Tech Stack

* **React.js**
* **Vite**
* **JavaScript**
* **CSS**
* **TMDB API** — Movie data and information

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Anit0/MovieExplorer.git
```

### 2. Navigate to the project

```bash
cd MovieExplorer
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown in your terminal.

## 🔑 API Configuration


If the project uses the TMDB API, create an environment file in the project root:

```text
.env
```

Add your TMDB API key according to the environment variable used by the project.

Example:

```env
VITE_TMDB_API_KEY=your_api_key_here
```

> Never commit your API key or `.env` file to GitHub.

## 📦 Build for Production

Create an optimized production build:

